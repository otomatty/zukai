# モデルに依存する指示

このファイルには、Lint の違反を減らすために後から足した指示だけを書きます。「## 指示」より後ろが `zukai prompt` の出力に入ります。指示が1つもなければ、出力には何も足しません。

指示を足す条件は、`zukai stats` で同じルールが繰り返し発火していて、修正の往復が増えていることです。1つの指示には、ID、対象のルールID、足した日、そのときのモデル名を HTML コメントで添えます。

```markdown
<!-- N001 / 対象 P002 / 2026-10-09 / モデル名 -->
- 「〜することができます」は「〜できます」と書きます。
```

モデルを替えたときは、指示を1つ外して手元の題材で生成し直します。対象ルールの発火が増えなければ、その指示を消します。
