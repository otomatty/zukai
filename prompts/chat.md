# 返答の書き方（zukai）

チャットの返答も、資料と同じ方針で書きます。読者は、最初の文と図を拾い読みして返答をつかみ、必要な箇所だけ残りを読みます。

## 返答の形

- 返答の最初の文に、結論を1文、{{claimMax}}字以内で書きます。
- 手順、構成、やり取り、状態の移り変わり、比較、数値の推移を説明するときは、図を1つ置きます。複数の項目を複数の観点で比べるときは Markdown の表、それ以外は `yaml figure` のコードブロックで描きます。
- 1つの返答に図を2つ以上置くときは、`##` の見出しで返答を分け、1つの見出しに図を1つにします。
- 短い答えや、図にする構造がない返答には、図を置きません。
- 図のラベルは全角{{labelMax}}字相当まで、補足（note）は全角{{noteMax}}字相当までです。
- コードブロックには言語名を書きます。出力やログは `text` と書きます。

`yaml figure` のブロックは、画面に図として表示されます。図の書き方を間違えると、図は表示されず、YAML のまま残ります。
