## 効果音

効果音は ZzFX で作ります。名前の付いた音を選ぶか、ZzFX の数値を自分で書きます。音の高さは、同じシーンで続けて鳴ると少しずつ上がります（`appear`、`bubble`、`chime`）。

| 書き方 | 内容 |
|---|---|
| `data-sfx="appear"` | その要素の最初のアニメーションが始まる時刻に、名前の付いた音を鳴らします |
| `zk.cue('chime', 3.2)` | シーンの3.2秒に、名前の付いた音を鳴らします |
| `data-zzfx="1,,520,.01,.02,.08"` | その要素の最初のアニメーションが始まる時刻に、ZzFX の数値で作った音を鳴らします。空の値は既定値になります |
| `zk.zzfx(3.2, 1, 0, 520, .01)` | シーンの3.2秒に、ZzFX の数値で作った音を鳴らします |
| `zk.sound(async (ctx) => { ... })` | WebAudio で自分で音を作ります。`ctx` は 48kHz の OfflineAudioContext で、時刻0がシーンの始まりです。音の最大値は1以下にします |

| 名前 | 合う動き |
|---|---|
| `appear` | 部品が現れる（`pop` も同じ音） |
| `bubble` | 吹き出しが出る |
| `draw` | 線を描く |
| `whoosh` | 場面が移る、物が素早く動く |
| `chime` | 強調する |
| `success` | 正解、完了 |
| `error` | 警告、× |
| `click` | 押す、選ぶ |
| `tick` | 数え上げ |
| `drop` | 着地する |
| `rise` | 盛り上がる |
| `vanish` | 消える |

ZzFX の数値は、次の順に21個までです。音量、ばらつき、周波数、attack、sustain、release、波形（0 正弦、1 三角、2 のこぎり、3 tan、4 ノイズ）、波形の曲がり、slide、deltaSlide、音程の跳び、跳ぶ時刻、繰り返し、ノイズ、変調、ビット落とし、ディレイ、sustain の音量、decay、トレモロ、フィルタ。フィルタは負の値がローパス、正の値がハイパスで、区切りの周波数は値の2倍です。ばらつきの乱数は種を固定するので、同じ原稿からは毎回同じ音になります。
