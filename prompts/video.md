# 動画の書き方

この原稿からは、資料に加えて解説動画も作ります。`#` の題名がオープニング、`##` のセクション1つが1つのシーンです。すべてのシーンの絵と動きを、あなたが1シーンずつ作ります。zukai は時刻の制御、字幕、シーンの切り替え、音声、書き出しと、壊れた動画を出さないための検査だけを受け持ちます。背景もキャラクターも zukai は描きません。動画の品質は、あなたの書くものでそのまま決まります。

## 台本

台本は、1人の語り手が、その内容を知らない視聴者に向けて、ていねいに説明する形にします。説明は、視聴者が抱きそうな疑問を投げかけ、原稿の根拠をもとに答え、わかりやすい例で確かめる、という順で進めます。

| 部分 | 置き場所 | 内容 |
|---|---|---|
| オープニング | 題名の直後の段落の後ろ | この動画のテーマと、動画で答える疑問を示します |
| 各シーン | 各セクションの説明文の後ろ | 疑問を投げかけ、根拠をもとに答え、例を挙げます |
| エンディング | 原稿の最後（`yaml narration ending` と `html motion ending`） | 要点を2〜3個にまとめ、オープニングの疑問への答えを示します。資料には出ません |

### 1シーンの流れ

1. **疑問を投げかける。** 最初の行は、視聴者が抱きそうな疑問の形にします。例: 「ログインした状態は、いつまで続くのでしょう？」
2. **根拠をもとに答える。** 答えは、そのセクションの主張文、図、説明文、根拠（`yaml refs`）に書かれていることだけで組み立てます。原稿にない事実や数値は足しません。根拠がコードや出典なら、「ガイドラインでは」「設定では」のように、何に基づく話かを言葉にします。
3. **例で確かめる。** 抽象的な説明のあとに、身近な例を1つ挙げます。例: 「たとえば、昼休みに席を離れて戻ってきたら、もう一度ログインが必要になります」。

疑問は、その内容を初めて聞く人が引っかかるところから選びます。

- 用語の意味。「そもそも〇〇とは何でしょう？」
- 理由。「なぜ、そうするのでしょう？」
- 無かった場合。「それが無いと、どうなるのでしょう？」
- ほかの方法との違い。「〇〇ではだめなのでしょうか？」
- 数字の意味。「30分は、長いのでしょうか、短いのでしょうか？」

### 根拠と例の見せ方

- 根拠は、画面にも示します。`zk.refs()` で、そのシーンの根拠（確かめ済みのコードの抜粋と引用）を読めます。出典の名前、引用の訳、コードの場所を、小さな札や引用の枠で出します。
- 例の場面は、本題の図と見分けがつくように描きます。たとえば、色を変える、吹き出しや枠で囲む、などです。
- 例の行には `example: true` を付けます。例の中の数値は、原稿の根拠と照らし合わせません。例ではない行の数値は、原稿にある数値だけを使います（V013）。

### 用語の補足

視聴者が知らないかもしれない用語は、初めて出てきたときに補足します。

- 語り手が「〇〇とは、〜のことです」と1〜2文で説明し、身近なものにたとえます。例: 「セッションIDは、ログインしたことを示す合言葉のようなものです」
- 画面にも、用語とひとことの説明を出すと伝わりやすくなります。
- 補足は、その用語が初めて出たときに1回だけします。補足が3つを超えるシーンは、用語を減らすか、シーンを分けます。

### ナレーションの書き方

```yaml narration
- ログインした状態は、いつまで続くのでしょう？
- 最後に操作してから、{#clock}30分で終わります。
- ガイドラインでは、{#ref}リスクの低いアプリの目安を、15分から30分としています。
- text: たとえば、昼休みに席を離れて戻ってきたら、もう一度ログインが必要です。
  example: true
- text: そのまま30分たつと、<short pause>{#expire}合言葉は消えてしまいます。
  style: 少し声を落として
```

- 説明文を読み上げるのではなく、聞いて分かる話し言葉に書き直します。視聴者に語りかける口調にし、括弧、矢印、スラッシュ、コードの識別子は使いません。
- 配列の1要素が字幕の1枚です。1要素は{{lineMax}}字以内を目安にします。
- 要素は文字列か、`text`、`style`、`example` を持つ形で書きます。`style` には、その行の語り口を日本語で書きます。書かなければ既定の語り口になります。
- `<short pause>`、`<laugh>`、`<sigh>` のような山括弧のタグは、読み上げの演技の指示になります。字幕には出ません。
- `{#名前}` は目印です。読み上げと字幕からは外れ、その語を読む時刻が、シーンの CSS 変数 `--名前` になります。名前は英数字とハイフンで書きます。
- 目印や `[` で始まる文は、YAML として読めなくなるので、`- '{#p1}まず…'` のように引用符で囲みます。

## シーン

ナレーションの後ろに `html motion` のブロックを1つ置き、そのシーンの絵と動きを作ります。オープニングのシーンは題名の直後のナレーションの後ろに、エンディングのシーンは `html motion ending` として原稿の最後に置きます。HTML、SVG、CSS、JS を自由に使えます。書かなかったシーンは、代わりに主張文と図だけの簡素な動きで出し、検査が V003 の error を返します。

- 舞台は 1920×1080 の `.zk-scene` です。書いた HTML はその中に入ります。位置は `position:absolute` で決めるのが確実です。背景はシーンごとに自分で描きます。
- 画面の下から190px は、字幕の帯が出ます。文字と主役の絵は、その上に置きます。
- ネットワークとファイルは使えません。画像は SVG で描くか、data URI で埋め込みます。
- class 名と id は、シーンごとに違う接頭辞を付けます。CSS はページ全体に効くので、ほかのシーンとぶつかります。

### 絵柄

科学解説アニメーションによくある、フラットなデザインで描きます。

- 円、角丸の四角、多角形を組み合わせ、単色の塗りで描きます。輪郭線、写真のような質感、ぼかし、`drop-shadow` は使いません。
- 背景は暗い単色か、ごく弱い2色のグラデーションにします。主役には、明るく彩度の高い色を使います。1シーンの色は、背景を除いて3〜4色に絞ります。
- 立体感は、同じ色の明るい面と暗い面の形で出します。影は、ずらした暗い色の図形で描きます。
- キャラクターや物は、単純な形で描きます。目は白い円と黒い円で描きます。既存の作品のキャラクターやロゴは、そのまま真似ません。
- 動きにはイーズイン・アウトを使い、出てくる物は少し行きすぎてから戻します（例: `cubic-bezier(.2,.8,.3,1.4)`）。止まっている物にも、浮く、揺れる、まばたきするといった小さな動きを続けます。
- カメラの動きは、シーン全体を包む要素を拡大したり平行移動したりして表します。
- 画面の文字は少なく、大きくします。ナレーションと同じ文は、字幕に出るので画面に書きません。

色は自由に決めます。zukai の配色は、CSS 変数として使えます。

| CSS 変数 | 用途 |
|---|---|
| `--zk-bg` | 既定の背景 |
| `--zk-night`、`--zk-navy`、`--zk-blue`、`--zk-sky`、`--zk-cyan`、`--zk-green`、`--zk-yellow`、`--zk-orange`、`--zk-red`、`--zk-pink`、`--zk-purple`、`--zk-white` | フラットな配色 |
| `--zk-font` | 日本語のフォント |

### 時刻

動画はコマ単位で撮るので、時刻はすべて zukai が決めます。時刻の0はシーンの始まりです。

| 書き方 | 時刻の合わせ方 |
|---|---|
| CSS アニメーション、Web Animations、SMIL | zukai が止めて、シーンの時刻に合わせます。`animation-delay` に下の CSS 変数を使うと、ナレーションに合わせられます |
| JS | `zk.scene((t, root, info) => { ... })` に渡した関数を、毎コマ呼びます。`t` はシーンの秒数、`root` はシーンの要素です。状態を積み上げず、`t` から計算します |

| CSS 変数 | 値 |
|---|---|
| `--narration-start` | ナレーションが始まる時刻 |
| `--duration` | シーンの長さ |
| `--l1`、`--l1-end`、`--l2`… | ナレーションの各行の始まりと終わり |
| `--目印の名前` | 目印の語を読む時刻 |

`info` は、そのときのナレーションの状態です。`info.index` は話している行の番号（話していなければ -1）、`info.example` はその行が例かどうか、`info.level` は声の大きさ（0〜1）です。シーンの要素の `data-talking` 属性も、話している間だけ `true` になります。

`Date`、`performance.now`、`setTimeout`、`setInterval`、`requestAnimationFrame`、`Math.random` は、zukai の時刻と、種を固定した乱数に置き換わります。ただし、タイマーで値を積み上げる書き方は、同じ時刻を撮り直したときに結果が変わるので使いません。

### セクションの図

資料の図を動画でも使うときは、`<zk-figure></zk-figure>` を置きます。図を自動の動き付きで置きます。`<zk-figure manual></zk-figure>` にすると、動きを付けずに置くので、自分で動かします。図の部品には `data-label`（箱の名前）、`data-part`（番号）、`data-kind`（`pop`、`draw`、`fade`）、`data-emphasis` の印が付いています。例: `[data-label="認証サービス"]`。図を使わず、内容を絵で描き直してもかまいません。

### シーンの設定

`<zk-options>` に、シーンの設定を書きます。書かなかった項目は既定値になります。

```html
<zk-options subtitles="on" transition="zoom" hold="1.5"></zk-options>
```

| 項目 | 値 | 内容 |
|---|---|---|
| `subtitles` | `on`、`off` | 字幕 |
| `transition` | `pan`、`fade`、`zoom`、`cut` | このシーンに入るときの切り替え。既定は `pan` |
| `hold` | 0〜10 | ナレーションの後に延ばす秒数。見せ場の動きを最後まで見せるときに使います |

### 音

| 書き方 | 内容 |
|---|---|
| `data-sfx="pop"` | その要素のアニメーションが始まる時刻に、用意した効果音を鳴らします。`pop`、`whoosh`、`draw`、`chime` があります |
| `zk.cue('chime', 3.2)` | シーンの3.2秒に、用意した効果音を鳴らします |
| `zk.sound(async (ctx) => { ... })` | 自分で音を作ります。`ctx` は 48kHz の OfflineAudioContext で、時刻0がシーンの始まりです。音の最大値は1以下にします |

## 検査

`zukai frames` は、次の項目を機械的に検査します。V001、V002（読み込み）、V105 の error になったシーンは、代わりの簡素な動きに差し替わります。

| ID | 内容 | 重さ |
|---|---|---|
| V001 | 読み込みが{{loadSec}}秒、1コマが{{frameSec}}秒で終わらない。無限ループを疑う | error |
| V002 | スクリプトが例外を出した。読み込みの例外は error、`zk.scene` の中の例外は warn | error / warn |
| V003 | シーンの html motion がない | error |
| V004 | オープニングのナレーションがない | error |
| V005 | エンディング（`yaml narration ending`）がない | error |
| V010 | `<zk-options>` に使えない値がある | warn |
| V012 | yaml narration を YAML として読めない | error |
| V013 | 例ではない行の数値が、原稿の主張文、図、説明文、根拠にない | warn |
| V014 | シーンの最初の行が疑問の形ではない。オープニングに疑問の形の行がない | warn |
| V101 | シーンの最後のコマで、文字が画面の外にはみ出す | warn |
| V102 | シーンの最後のコマで、文字が字幕の帯に重なる | warn |
| V103 | 文字が{{minFont}}px より小さい | warn |
| V104 | アニメーションがシーンの長さを超えて続く | warn |
| V105 | シーンの要素が{{maxElements}}個を超える | error |
| V106 | シーンが{{maxScene}}秒、動画全体が{{maxTotal}}秒を超える | warn |
| V201 | 同じ時刻のコマが、撮るたびに変わる | warn |
| V301 | `zk.sound` の音が割れる | warn |

## 確かめ方

1. `{{cli}} frames 原稿.md --sheet` を実行します。検査の結果と、シーンごとに6つの時刻のコマを並べた画像（`原稿.sheet-番号.png`）が出ます。`--scene=番号` で1つのシーンだけを確かめられます。
2. 画像を開いて見ます。動きの順番、ナレーションとの合い方、文字の読みやすさ、構図、絵柄を確かめ、error と warn を直します。特定の時刻を大きく見たいときは、`--at=秒,秒` を使います。
3. 手順1と2は2回までです。
4. `{{cli}} video 原稿.md` で MP4 を書き出します。
