# 効果音を増やす案のスパイク

動画の効果音を増やす2つの案を、聞き比べるためのスパイクです。本体のコードからは使いません。

**結果: ZzFX を採用しました。** 12個の音の値は、`src/video/sfx.js` の `PRESETS` に移しています。ZzFX 本体は、MIT のライセンス表示ごと `src/video/vendor/` に取り込みました。採用前の合成音は削除したので、聞き比べの表は ZzFX と Kenney の2列です。

| 案 | 中身 | ライセンス | 動画への組み込み方 |
|---|---|---|---|
| ZzFX | 21個の数値から効果音を作る小さなライブラリ（v1.4.0） | MIT（Frank Force） | ページに入れ、AI が `zk.sound` の中で数値を決めて音を作る |
| Kenney | Interface Sounds（100個）と Impact Sounds（130個）の音のファイル | CC0（www.kenney.nl） | 選んだファイルを設定の `video.sfx.files` に書く（手元にだけある音のファイルは `zukai config set video.sfx.files.appear パス --scope=local`）。今の仕組みのまま使える |

## 作り方

素材はリポジトリに入れていません。次の3つを取得し、Kenney の2つは1つのフォルダに `interface` と `impact` という名前で展開します。

| ファイル | 取得元 |
|---|---|
| `zzfx-1.4.0.tgz` | https://registry.npmjs.org/zzfx/-/zzfx-1.4.0.tgz |
| `kenney_interface-sounds.zip` | https://kenney.nl/assets/interface-sounds |
| `kenney_impact-sounds.zip` | https://kenney.nl/assets/impact-sounds |

```bash
node spikes/sfx/make.mjs --zzfx=<展開した package/ZzFX.js> --kenney=<interface と impact を置いたフォルダ>
```

`spikes/sfx/out/index.html` をブラウザで開くと、動きごとに2つの案を並べて聞けます。出力は Git の管理に入れません。

## 比べ方

- 動画で使いそうな12個の動き（現れる、吹き出し、線を描く、場面が移る、強調、正解、警告、押す、数え上げ、着地、盛り上がる、消える）に、それぞれの案の音を1つずつ当てています。
- 「1シーン分の流れ」は、部品が3つ現れ、線が伸び、強調し、吹き出しが出て、数を数え、正解で終わり、場面が移る約6秒の音です。動画の中での聞こえ方を確かめるのに使います。
- 音の大きさは、平均の大きさ（RMS）を -16dB に合わせ、最大値が -1dB を超えないようにそろえています。

## 機械で確かめたこと

- 3つの案とも、12個の音が無音にならず、最大値が -1dB 以下に収まることを確かめました。
- ZzFX の音を、スペクトログラムで確かめました。ノイズで作る音（線を描く、場面が移る）は、最初は高い音域まで鳴っていて耳障りでした。ローパスに直したところ、今の合成音に近い帯域に収まりました。ZzFX の `filter` は、負の値がローパス、正の値がハイパスで、区切りの周波数は値の2倍です。
- Kenney の音は、立ち上がりが鋭い分、最大値で頭打ちになり、平均の大きさが -16dB に届かないものがあります（吹き出し、強調、数え上げ、盛り上がる、消える）。動画で使うときは、少し大きめに混ぜる必要があります。

## 人が確かめること

音の印象は機械では判断できません。index.html で聞き比べ、次の点を決めます。

- フラットな絵柄の解説動画に合うのは、どちらの音か
- 12個の動きに当てた音が、その動きらしく聞こえるか
- 1シーン分の流れで、音がうるさすぎないか
