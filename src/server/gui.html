    設定
    

    値を変えて「保存」を押すと、選んだ置き場所の設定ファイルに書きます。「既定に戻す」は、今効いている置き場所から値を消します。下の置き場所ほど優先します（この PC < チーム < 手元 < 本人だけ < 環境変数）。
    

    

    

    

    

    


    

    

    今のテーマ
    

    読み込んでいます…
    

    

    見本
    

    今のテーマで、すべての図の型を描いた見本を表示します（zukai theme preview と同じです）。
    

    


    案を比べる
    

    今のテーマと案を、同じ図で横に並べます。1行に1つの案を書きます。例: emphasis.box=tint、複数の値は + でつなぎます。
    


    


    テーマのフォルダを作る
    

    tokens.json（色とフォント）と rules.md（描き方のルール）のひな形を、プロジェクトの中に作ります。作ったあとで「このテーマを使う」を押すと、チームの設定の theme に書きます。
    

    

    

    


    

    

    接続の状態
    

    • 確かめています…
    

    資料をページとして公開するには、「資料」タブで資料を選び、「Confluence に公開」を押します。Lint の error が残っている資料は公開しません。初回はページを作り、原稿の先頭にページ ID を書き込みます。2回目からは同じページを更新します。
